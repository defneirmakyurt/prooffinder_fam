# What to hand in: H-C1 (verbatim from the official problem text)
C1 to C4. Hand in the values, and for each value an explicit labelling that attains it as a list of the 2^d vertices in increasing label order, written as 0/1 strings.
These cells are marked correct on the values alone, but a value with no labelling behind it will not survive the later cells, which build on the construction.
Computation. A lower-bound proof may be computer-assisted. If it is, include the code; it must run in under 10 minutes on a laptop, and you must explain why the computation proves the bound.
Status. Say clearly which cells you consider solved and which are partial.
