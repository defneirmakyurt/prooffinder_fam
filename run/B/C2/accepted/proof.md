Statement: For every k >= 1, D_B(T_k) = k^2 - k (no exceptions: k=1 gives 0, k=2 gives 2). LOWER bound (Part A): witness lambda^(k) = (k-1, k-1, k-2, ..., 2, 1, 1) (lambda^(1) = (1)), d_B(lambda^(k)) = k^2 - k. UPPER bound (Part B): d_B(lambda) <= k^2 - k for all lambda |- T_k; the architecture follows Griggs-Ho (1998) Thm 3.7, with every lemma re-derived here in full (their Lemma 3.5 "continue this process" written as an explicit induction). Part 0.3 proves (self-contained) that delta_k is the only cyclic partition of T_k and every orbit reaches it, so the B-C1 assumption is not needed.

Notation. A partition is identified with its diagram S = {(i,j) : 1 <= j <= s, 1 <= i <= lambda_j} (column j = pile j, row i = level).
Diagonal of a cell: w(i,j) = i + j - 1. Diagonal w has the w positions (w,1), (w-1,2), ..., (1,w); call the position (w+1-j, j) "column j of diagonal w".
D_k := diagram of delta_k = all cells with w <= k (column j of delta_k has height k+1-j, top cell on diagonal k).

## Part 0. The shift on diagrams (proved here)

0.1 Lemma. Let lambda have s parts, diagram S. Define S' = rot(S) by (i,j) -> (i-1, j+1) if i >= 2, and (1,j) -> (j,1).
 (a) rot preserves every diagonal and acts on diagonal w as the cyclic shift column j -> j+1 (j < w), column w -> column 1.
 (b) S' has column 1 of height s and column j+1 of height lambda_j - 1 (1 <= j <= s); these are exactly the parts of B(lambda) (plus zeros).
 (c) If s >= lambda_1 - 1 then S' is a Young diagram, so diagram(B(lambda)) = S'.
 (d) If s < lambda_1 - 1 then diagram(B(lambda)) is obtained from S' by moving every cell (i,j) of S' with i > s to (i, j-1) (all such cells have j >= 2); each moved cell drops from diagonal w to w-1, and at least one cell moves.
Proof. (a): (i-1)+(j+1)-1 = i+j-1; (j,1) and (1,j) both lie on diagonal j. Column index j -> j+1, and (1,w) (column w) -> (w,1) (column 1).
(b): the cells (1,1),...,(1,s) go to (1,1),...,(s,1): column 1 of height s. The cells (i,j), 2 <= i <= lambda_j, go to (i-1,j+1): column j+1 of height lambda_j - 1. B(lambda) has exactly the parts s and the positive lambda_j - 1.
(c): column heights of S' are s, lambda_1 - 1 >= lambda_2 - 1 >= ...; weakly decreasing iff s >= lambda_1 - 1; a weakly decreasing list of column heights is a Young diagram with the right parts.
(d): the diagram of the sorted partition has row i of length r_i = #{columns of S' of height >= i}. For i <= s, column 1 has height >= i and the columns j >= 2 with height >= i form an initial segment 2..m (heights decreasing from column 2 on), so row i of S' is already {1..r_i}: unchanged. For i > s, column 1 has height s < i, so row i of S' is {2..r_i+1}; in the sorted diagram it is {1..r_i}: every cell (i,j) with i > s moves to (i,j-1). Since lambda_1 - 1 > s, the cell (s+1, 2) exists: at least one move. []

0.2 Lemma. B(delta_k) = delta_k, so delta_k is cyclic. Proof: parts k-1,...,1,0 -> positive ones k-1..1, plus new part s = k. []

0.3 Lemma (convergence; Griggs-Ho Thm 2.1 argument, written out). For n = T_k every orbit reaches delta_k, and delta_k is the only cyclic partition of T_k.
Proof. Energy E(S) := sum over cells of their diagonal index. Diagonal w has exactly w positions, so D_k is the set of all T_k positions on diagonals 1..k. For S |- T_k with S != D_k: #(cells of S on diagonals > k) = #(holes of S on diagonals <= k) =: h >= 1 and E(S) - E(D_k) = sum_{cells on diag w>k} (w-k) + sum_{holes on diag w<=k} (k-w) >= h >= 1. By 0.1, one shift preserves E if no slide occurs and lowers E by >= 1 if a slide occurs (0.1(d)).
Claim: if S != D_k then, for the index w defined next, a slide occurs at one of the steps 0, 1, ..., w(w+1)-1 of the orbit of S. Let W0 = largest diagonal carrying a cell (W0 >= k+1) and w0 = smallest diagonal with a hole (w0 <= k). Let w be the largest index < W0 whose diagonal has a hole (exists: w0 < W0). Diagonal w+1 carries a cell: if w+1 = W0 by definition of W0; otherwise diagonal w+1 has no hole (maximality of w), so it is full, hence non-empty. Fix a hole on diagonal w at column a and a cell on diagonal w+1 at column b. If no slide occurs during steps 0..tau-1, the diagram at time tau is rot^tau(S) (0.1(c)), in which (by 0.1(a)) that hole sits at column a+tau (mod w) and that cell at column b+tau (mod w+1). By CRT (gcd(w,w+1)=1) choose tau in [0, w(w+1)) with a+tau = w (mod w) and b+tau = 1 (mod w+1). At time tau, (1,w) (column w of diagonal w) is empty, so the number of parts s <= w-1 (row 1 is an initial segment); (w+1,1) (column 1 of diagonal w+1) is occupied, so mu_1 >= w+1 > s+1; by 0.1(d) the next step is a slide. So some slide occurs at a step <= tau.
Hence if the orbit never met delta_k, slides would occur infinitely often and E (a non-negative integer, never increasing) would decrease infinitely often: impossible. So B^t(lambda) = delta_k for some t, and then for all larger t (0.2). If mu is cyclic, B^p(mu) = mu (p >= 1) gives mu = B^{mp}(mu) = delta_k for large m. []

## Part A. Lower bound: d_B(lambda^(k)) = k^2 - k for every k >= 1 (complete)

A.0 k = 1: T_1 = 1, the only partition is (1) = delta_1, cyclic (0.2), d_B = 0 = 1^2 - 1. From now on k >= 2.

A.1 Witness. lambda^(k) := (lambda_1, ..., lambda_{k+1}) with lambda_1 = k-1, lambda_j = k+1-j (2 <= j <= k), lambda_{k+1} = 1. It is weakly decreasing (k-1 >= k-1 >= k-2 >= ... >= 1 >= 1), positive, and sums to (k-1) + (T_k - k) + 1 = T_k. (k=2: (1,1,1); k=3: (2,2,1,1).)
Its diagram is D_k minus the cell (k,1) (= column 1 of diagonal k) plus the cell (1,k+1) (= column k+1 of diagonal k+1): columns 2..k agree with delta_k, column 1 is one shorter, column k+1 is new of height 1.

A.2 Family. For a in {1..k}, b in {1..k+1} let S(a,b) := D_k \ {column a of diagonal k} U {column b of diagonal k+1} (a set of T_k cells).
Claim: if S(a,b) is the diagram of a partition mu, then (i) mu has s = k - [a=k] + [b=k+1] parts and mu_1 = k - [a=1] + [b=1]; (ii) if not (a = k and b = 1) then diagram(B(mu)) = S(a+1 mod k, b+1 mod k+1) (residues taken in {1..k}, {1..k+1}); (iii) if a = k and b = 1 then B(mu) = delta_k.
Proof. (i) s = number of cells in row 1. Row-1 cells are (1,j) = column j of diagonal j; D_k has (1,1..k); the removed cell is in row 1 iff a = k (it is (k+1-a, a)); the added cell (k+2-b, b) is in row 1 iff b = k+1. Similarly mu_1 = number of cells in column 1: D_k has (1..k, 1); removed cell in column 1 iff a = 1; added iff b = 1.
(ii) Since k >= 2, a = k excludes a = 1. s >= k-1 always and mu_1 - 1 <= k; s < mu_1 - 1 forces s = k-1 (so a = k, b != k+1) and mu_1 = k+1 (so b = 1). So if not (a = k and b = 1) then s >= mu_1 - 1, and by 0.1(c),(a) diagram(B(mu)) = rot(S(a,b)); rot maps each full diagonal of D_k onto itself and shifts the hole and the extra cell by one column cyclically: rot(S(a,b)) = S(a+1, b+1) (cyclically).
(iii) a = k, b = 1: s = k - 1, mu_1 = k+1 > s + 1, so 0.1(d) applies. rot(S(k,1)) = S(1,2) as a set: hole at (k,1), extra cell at (k,2). The cells of rot(S(k,1)) in rows > s = k-1: rows >= k. D_k has only (k,1) in rows >= k, and it is the hole; the extra cell (k,2) is in row k. So exactly (k,2) moves to (k,1), filling the hole: result D_k = delta_k. []

A.3 Orbit. By A.1, lambda^(k) = S(1, k+1). Put a_t = 1 + (t mod k), b_t = 1 + ((t + k) mod (k+1)). By A.2(ii) and induction, diagram(B^t(lambda^(k))) = S(a_t, b_t) for all t <= t* where t* is the least t >= 0 with a_t = k and b_t = 1 (at every earlier step the hypothesis of (ii) holds; each S(a_t,b_t) so produced is the diagram of the partition B^t(lambda^(k)), so the hypothesis "S(a,b) is a diagram" holds by induction).
a_t = k <=> t = -1 (mod k); b_t = 1 <=> t + k = 0 (mod k+1) <=> t = 1 (mod k+1). Since gcd(k,k+1) = 1, the solutions form one class mod k(k+1) (CRT). t0 = k^2 - k - 1 is a solution: k^2 - k - 1 = -1 (mod k); mod k+1, k = -1 so k^2 - k - 1 = 1 + 1 - 1 = 1. For k >= 2, 0 <= t0 < k(k+1), so t* = t0 = k^2 - k - 1.
By A.2(iii), B^{k^2-k}(lambda^(k)) = delta_k. For 0 <= t <= k^2-k-1, B^t(lambda^(k)) has diagram S(a_t,b_t), which contains a cell on diagonal k+1, so it is not delta_k.

A.4 Not cyclic before time k^2-k. Let 0 <= t < k^2 - k and mu = B^t(lambda^(k)). If mu were cyclic, B^p(mu) = mu for some p >= 1, hence mu = B^{mp}(mu) for all m >= 1; choose mp >= k^2 - k - t; then B^{mp}(mu) = B^{mp - (k^2-k-t)}(delta_k) = delta_k by A.3 and 0.2. So mu = delta_k, contradicting A.3. Hence d_B(lambda^(k)) = k^2 - k (B^{k^2-k}(lambda^(k)) = delta_k is cyclic by 0.2).
(This part uses no fact about which partitions of T_k are cyclic beyond 0.2.) Hence D_B(T_k) >= k^2 - k for all k >= 1.

## Part B. Upper bound d_B(lambda) <= k^2 - k for lambda |- T_k (architecture of Griggs-Ho Thm 3.7, all lemmas re-derived)

By 0.3 (or the B-C1 assumption, which says the same), d_B(lambda) = min{t : B^t(lambda) = delta_k} for lambda |- T_k.

B1 (c-sequence). For lambda |- n with s parts let c_u := number of parts of B^{u-1}(lambda), u >= 1 (so c_1 = s). By induction on t, the parts of B^t(lambda) are the positive numbers among {lambda_j - t : j <= s} U {c_u - (t - u) : 1 <= u <= t}. (t=0 trivial; step: B subtracts 1 from each part, drops non-positive values, which is the same as subtracting 1 from every listed number and keeping positive ones, and adds the part c_t = c_t - 0.) Hence
   c_{t+1} = #{j : lambda_j >= t+1} + #{u <= t : c_u >= t+1-u}.   (*)
Write f_{i,j} = [lambda_j >= i] and e_{i,u} = [c_u >= i - u] (u < i); then c_i = sum_j f_{i,j} + sum_{u<i} e_{i,u} ("row i"), and for fixed column (j or u) the entries are 1 on an initial segment of rows (monotone in i). Every c_u >= 1 (n >= 1), so e_{i,i-1} = 1.

B2 (row comparison; Griggs-Ho "comparing rows"). c_{i+1} <= c_i + 1, with equality iff f_{i+1,j} = f_{i,j} for all j and e_{i+1,u} = e_{i,u} for all u < i. Proof: row i+1 consists of the entries f_{i+1,j} <= f_{i,j}, e_{i+1,u} <= e_{i,u} (u < i) (monotonicity in the row index) and the new entry e_{i+1,i} = 1. So c_{i+1} = 1 + (sum of entries each <= the corresponding entry of row i) <= 1 + c_i, with equality iff all those entries are equal. [] (This is Griggs-Ho Prop 3.2(1).)
Flip form: call an old column (a lambda-column j, or a c-column u < i) a FLIP at row i if its entry is 1 in row i and 0 in row i+1; for a c-column u this happens iff u + c_u = i ("column u ends at row i"), for a lambda-column iff lambda_j = i. With L_i := number of flips at row i, c_{i+1} = c_i + 1 - L_i. In particular c_{i+1} = c_i + 1 iff L_i = 0 (rows i and i+1 agree on all old columns), and c_{i+1} = c_i iff L_i = 1 (they agree on all old columns except exactly one flip).

B3 (Sandwich; Griggs-Ho Prop 3.2(3)). If i < j and c_i < x < c_j then there are p < q with i <= p, q <= j, q >= p+2 and (c_p, ..., c_q) = (x-1, x, ..., x, x+1). Proof: let p be the largest index in [i, j) with c_p <= x - 1 (exists: p = i qualifies). Then c_{p+1} >= x (if p+1 < j by maximality; if p+1 = j since c_j > x), and c_{p+1} <= c_p + 1 <= x by B2, so c_p = x-1, c_{p+1} = x. All indices in (p, j) have c >= x. Let q be the least index > p+1 with c_q != x; q <= j since c_j > x. c_q >= x (as q <= j and either q < j or q = j) and c_q <= c_{q-1} + 1 = x + 1, so c_q = x+1, q >= p+2. []

B4 (end of the orbit; Griggs-Ho Lemma 3.3(1)). For n = T_k and t = d_B(lambda) >= 1: c_{t+1} = c_{t+2} = ... = k and c_t = k-1. Proof: B^t(lambda) = delta_k has k parts and is fixed (0.2), so c_u = k for u >= t+1. Let mu = B^{t-1}(lambda) != delta_k (minimality of t, and delta_k cyclic). B(mu) = delta_k contains the part c_t, so c_t <= k; B2 gives c_t >= c_{t+1} - 1 = k-1. If c_t = k then mu has k parts whose values minus 1 give k-1 positive values equal to k-1, ..., 1 and one zero, i.e. mu = delta_k, contradiction. So c_t = k-1. []

B5 (Griggs-Ho Lemma 3.3(2); proof written out). For n = T_k and t = d_B(lambda) >= k+1, at least one holds: (i) (c_p..c_q) = (k-1, k, ..., k, k+1) for some t-k <= p < q <= t-1, q >= p+2; (ii) (c_p..c_q) = (k-2, k-1, ..., k-1, k) for some t-k+1 <= p < q <= t+1, q >= p+2.
Proof. By B4, c_t = k-1 and c_u = k for u >= t+1. Row t contains the k entries e_{t,t-k}, ..., e_{t,t-1} (t-k >= 1), whose sum is <= c_t = k-1, so one of them is 0; e_{t,t-1} = 1 (B1), so there is i in [t-k, t-2] with e_{t,i} = 0; take i maximal, so e_{t,u} = 1 for u in [i+1, t-1]. Since c_{t+1} = c_t + 1, L_t = 0 (B2): e_{t+1,i+1} = e_{t,i+1} = 1. Hence c_{i+1} >= (t+1) - (i+1) = t - i, and e_{t,i} = 0 gives c_i <= t - i - 1; with c_{i+1} <= c_i + 1 (B2): c_i = t-i-1, c_{i+1} = t-i.
 Case i >= t-k+1: c_i = t-i-1 <= k-2 < k-1 < k = c_{t+1}; B3 with x = k-1 on [i, t+1] gives (ii) with p >= i >= t-k+1, q <= t+1.
 Case i = t-k: c_{t-k} = k-1, c_{t-k+1} = k. If some j in [t-k+2, t-1] has c_j <= k-2: B3 with x = k-1 on [j, t+1] gives (ii) with p >= j >= t-k+2. If some such j has c_j >= k+1: B3 with x = k on [t-k, j] (c_{t-k} = k-1 < k < c_j) gives (i) with p >= t-k, q <= j <= t-1. Otherwise c_j in {k-1, k} for all j in [t-k+2, t-1], and c_{t-k+1} = k; so c_u <= k for all u in [t-k+1, t-1]. Row t has exactly c_t = k-1 ones and e_{t,u} = 1 for the k-1 indices u in [t-k+1, t-1]; so these are all the ones of row t. By B1 the parts of mu := B^{t-1}(lambda) are the positive numbers among lambda_j - (t-1) and c_u - (t-1-u) (u <= t-1), and a column contributes a positive part iff its entry in row t is 1. So the parts of mu are c_u - (t-1-u), u in [t-k+1, t-1], and their sum is <= sum_{v=0}^{k-2} (k - v) = k + (k-1) + ... + 2 = T_k - 1 < T_k = |mu|, a contradiction. []

B6 (Griggs-Ho Lemma 3.4; proof written out). For lambda |- n >= 1, if (c_p, ..., c_{p+m}) = (m-2, m-1, ..., m-1, m) then p + m <= n + 1.
Proof. c_p = m-2 >= 1, so m >= 3. Column p ends at row p + m - 2: e_{p+m-2,p} = 1, e_{p+m-1,p} = 0 (so also e_{p+m,p} = 0). For u in [p+1, p+m-1], c_u = m-1, so column u has ones in rows u+1..u+m-1, which contain row p+m: e_{p+m,u} = 1 (m-1 ones). Row p+m has c_{p+m} = m ones, so exactly one further 1, in a column Z not in [p, p+m-1].
 If Z is a lambda-column j: lambda_j >= p+m, and lambda_j <= n, so p+m <= n.
 If Z is a c-column u0 (then u0 <= p-1): suppose u0 >= 2. Then e_{p+m,u0-1} = 0 (the only ones of row p+m are u0 and [p+1,p+m-1]). c_{p+m} = c_{p+m-1} + 1, so L_{p+m-1} = 0 and row p+m-1 agrees with row p+m on old columns: e_{p+m-1,u0} = 1, e_{p+m-1,u0-1} = 0. c_{p+m-1} = c_{p+m-2} (= m-1, as p+m-2 >= p+1), so L_{p+m-2} = 1, and column p is a flip at row p+m-2; so it is the only one, and rows p+m-2, p+m-1 agree on the columns u0, u0-1 (both != p): e_{p+m-2,u0-1} = 0. So c_{u0} >= (p+m) - u0 and c_{u0-1} <= (p+m-2) - (u0-1) - 1 = p+m-u0-2, i.e. c_{u0} >= c_{u0-1} + 2, contradicting B2. Hence u0 = 1, and e_{p+m,1} = 1 gives c_1 >= p+m-1; c_1 = s <= n, so p+m <= n+1. []

B7 (Griggs-Ho Lemma 3.5; proof written out, their "continue this process" made an induction). For lambda |- n >= 1: if q >= p+3 and (c_p..c_q) = (x-1, x, ..., x, x+1) then either p <= x or there is a pattern (c_p'..c_q') = (x'-1, x', ..., x', x'+1) with x' <= x, 2 <= q'-p' < q-p and p - x <= p' < q' <= p+1.
Proof. Assume p >= x+1. The x entries e_{p,p-x}, ..., e_{p,p-1} (p-x >= 1) lie in row p, which has c_p = x-1 ones, so one is 0; e_{p,p-1} = 1, so take p' maximal in [p-x, p-2] with e_{p,p'} = 0; then e_{p,u} = 1 for u in [p'+1, p-1]. c_{p+1} = c_p + 1 gives L_p = 0: e_{p+1,u} = 1 for u in [p'+1, p] (u = p is the new entry). As in B5, e_{p+1,p'+1} = 1 and e_{p,p'} = 0 give, with B2, c_{p'} = y-1 and c_{p'+1} = y where y := p - p' in [2, x].
 Invariant I(m) (m >= 1): c_{p'+1} = ... = c_{p'+m} = y, and e_{p+m,u} = 1 for all u in [p'+m, p+m-1]. I(1) holds. Note c_{p'+m} = y means column p'+m ends at row p'+m+y = p+m, so it is a flip at row p+m.
 Step. Assume I(m). (a) If p+m = q-1: c_q = c_{q-1} + 1 forces L_{q-1} = 0, but column p'+m is a flip at row q-1: contradiction. So p+m <= q-2, hence c_{p+m} = c_{p+m+1} = x and L_{p+m} = 1; the unique flip is column p'+m, so row p+m+1 agrees with row p+m on the other old columns: e_{p+m+1,u} = 1 for u in [p'+m+1, p+m] (u = p+m is the new entry). (b) e_{p+m+1,p'+m+1} = 1 gives c_{p'+m+1} >= y, and B2 gives c_{p'+m+1} <= c_{p'+m} + 1 = y+1. If c_{p'+m+1} = y+1, stop with q' := p'+m+1; else I(m+1) holds.
 Termination: by (a), I(m) forces m <= q-2-p, so the process stops at some m <= q-p-2, giving the pattern (c_{p'}, ..., c_{q'}) = (y-1, y, ..., y, y+1) with q'-p' = m+1 in [2, q-p-1], i.e. 2 <= q'-p' < q-p. Put x' = y <= x; p' >= p-x. Finally q' <= p+1: the indices p'+1..q'-1 carry the value y and q' carries y+1; if q' >= p+2 then indices p and p+1 would both lie in [p'+1, q'-1] (p' <= p-2), forcing c_p = c_{p+1} = y, but c_p = x-1 != x = c_{p+1}. []

B8 (Griggs-Ho Lemma 3.6; proof written out). If (c_p, c_{p+1}, c_{p+2}) = (x-1, x, x+1) then p <= x.
Proof. Suppose p > x, i.e. p - 1 > x - 1 = c_p. Row p contains the p-1 entries e_{p,1}, ..., e_{p,p-1} (all counted in c_p), so at most c_p < p-1 of them are 1: some e_{p,i} = 0 with i <= p-1; since e_{p,p-1} = 1 (B1), i <= p-2. Take i maximal: e_{p,i} = 0, e_{p,i+1} = 1. By B2 equality (c_{p+1} = c_p + 1, then c_{p+2} = c_{p+1} + 1): e_{p+1,i+1} = e_{p,i+1} = 1 and e_{p+2,i+1} = e_{p+1,i+1} = 1. So c_{i+1} >= (p+2) - (i+1) = p - i + 1, while e_{p,i} = 0 gives c_i <= p - i - 1. Then c_{i+1} >= c_i + 2, contradicting B2. []

B9 (assembly; Griggs-Ho proof of Thm 3.7, counting written out). Let lambda |- T_k, t = d_B(lambda).
 - k = 1, 2: exhaustive by hand: k=1 only (1), d=0. k=2: (2,1) fixed; (3) -> (2,1); (1,1,1) -> (3) -> (2,1); max 2 = k^2-k.
 - k >= 3 and t <= k: t <= k < k^2 - k.
 - k >= 3, t >= k+1: by B5 (i) or (ii) holds.
   * (ii) with q = p + k: then p = t-k+1 (forced by the ranges p >= t-k+1, q <= t+1), and B6 (m = k) gives p + k <= n + 1, so t = p + k - 1 <= n = k(k+1)/2 <= k^2 - k (since k >= 3).
   * otherwise q - p <= k - 1 and p >= t - k. Set P_0 = (p, q, x) (x = k or k-1 <= k). While the current pattern (p_i, q_i, x_i) has q_i - p_i >= 3 and p_i > x_i, apply B7 to get (p_{i+1}, q_{i+1}, x_{i+1}) with x_{i+1} <= x_i <= k, q_{i+1} - p_{i+1} <= q_i - p_i - 1, p_{i+1} >= p_i - x_i >= p_i - k. The length q_i - p_i starts <= k-1, drops by >= 1 per step, and stays >= 2, so at most k-3 steps occur. The process stops at some m <= k-3 with p_m <= x_m <= k (either B7's first alternative, or q_m - p_m = 2 and B8). Hence p_0 <= p_m + m k <= k + (k-3)k = k^2 - 2k, and t <= p_0 + k <= k^2 - k.
 So d_B(lambda) <= k^2 - k for all lambda |- T_k, i.e. D_B(T_k) <= k^2 - k. With Part A: D_B(T_k) = k^2 - k for every k >= 1.

## Part C. Computations (sanity only; prove nothing for all k)

Conclusion. Established here (written proofs, no citation used as proof): D_B(T_k) = k^2 - k for every k >= 1; lower bound by the explicit witness lambda^(k) (Part A), upper bound by Part B (Griggs-Ho architecture, all lemmas re-derived).
