# Where the argument stops

1. **Direction 3 for $k\ge11$ (rung R9).** Assume (H) and $\lambda\in E_k$. One must show $B^{j_k}(\lambda)=P_k$. Equivalently: $P_k$ is the only partition with $d_B=2k+1$ that has a backward chain of length $j_k=k^2-4k-2$. The data show that the orbits of all maximisers merge at exactly step $j_k$, for $6\le k\le10$. A proof would need a structural control of long backward chains, e.g. the potential/diagonal analysis behind the upper bound (H) itself, sharpened to show that equality forces the orbit through $P_k$. (H), as a bare inequality, gives only "no preimage" (Step 8) and nothing about where the orbit goes.

2. **Closed-form listing (rung R10).** $A_k=B^{-j_k}(P_k)$ is generated by iterating the explicit preimage rule (Step 3). A direct rule is still missing.
   - The natural candidate is the conjugate box $\max(0,k+3-2i)\le\lambda'_i\le\max(0,2k-1-2i)$. It contains $E_k$ for all $k\le10$, but it is strictly larger for $k=6,8,9,10$ (extra 1, 3, 24, 167 members).
   - Grouping maximisers by the multiset of "end times" $t+\ell(B^t\lambda)$, $0\le t\le k-2$, gives 1, 1, 2, 7, 20, 51 classes for $k=4,\dots,9$. There is no evident pattern.

3. **Nonemptiness of $A_k$ for $k\ge13$.** This is not proved here. It is the $C3(b)$ lower bound, which is not among my allowed assumptions.
