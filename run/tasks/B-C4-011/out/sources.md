- Conclusion: a proof of D_B(T_{k-1}+1) <= (k-1)(k-3) for all k >= 5 was **not found** in Griggs-Ho 1998, Hopkins-Jones 2006, Hopkins 2012, Drensky 2015, Eriksson-Jonsson 2017, Pham 2022/thesis, Harris-Nguyen 2023, Mestrovic 2026, Meyerowitz et al. 2026, OEIS, or the web searches above. The most recent explicit status statements found (Hopkins 2012, Eriksson-Jonsson 2017) call the Griggs-Ho values conjectural. This is NOT a claim that the statement is open: Etienne 1991 and Igusa 1985 were not opened.
